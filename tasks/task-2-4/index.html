Multimodal Search over a Paper Corpus

Build a search engine over a large collection of research-paper PDFs. Given a query, the system should find relevant material using both the textual and visual content of the papers.

Domain
research-paper search
Primary focus
multimodal and text retrieval
Primary metric
Accuracy

Runtime and requirements

  • Agent time budget: up to 120 minutes
  • Python: 3.12
  • Compute: 16 CPU cores, 32 GiB memory, 100 GiB storage
  • GPU required: no
  • Network: restricted — allowlisted resources only

Public input and output contract

Inputs

  • /task/data/corpus/ — a directory containing research-paper PDFs, including text, figures, and tables.
  • /task/data/validation/queries.jsonl — public development queries.
  • /task/data/validation/ground_truth.jsonl — relevance labels for the public queries.

Outputs

  • JSONL retrieval results — one highest-ranked paper per query, with its document identifier, PDF page number, and supporting evidence.

The submission must provide executable build.sh and run.sh entry points under /app.

Evaluation

A hidden query passes when the returned paper is relevant and its cited evidence is grounded in the PDF. The task score is the average held-out Accuracy.

Missing results count as incorrect queries. Invalid output or integrity violations result in a score of 0.
