Local variable fonts used by the leaderboard UI.

- Geist: https://github.com/google/fonts/tree/main/ofl/geist
- Google Sans Code: https://github.com/google/fonts/tree/main/ofl/googlesanscode

Converted from the upstream variable TTFs to WOFF2 with FontTools, preserving all glyphs and weights. Each font is licensed under the accompanying SIL Open Font License 1.1. The website makes no third-party font requests.
